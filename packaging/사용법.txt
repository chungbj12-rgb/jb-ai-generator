  JB스포츠 AI 블로그 생성기 — 사용법 (공유 패키지)
================================================================================

■ 포함 구성
  1) 바탕화면 앱 방식     → 실행.bat 더블클릭
  2) 크롬 확장 프로그램   → chrome-extension 폴더
  3) Electron 데스크톱    → desktop 폴더 (선택, 개발자용)

■ 1. 바탕화면 앱 (가장 쉬운 방법)
  1. ZIP 압축을 풀어 원하는 폴더에 둡니다. (경로는 자유롭게 이동 가능)
  2. 「start.bat」(또는 실행.bat)을 더블클릭합니다.
  3. 브라우저 창이 열리면 이메일·비밀번호로 로그인합니다.
  4. 키워드, 주제, CTA(선택)를 입력 후 「블로그 글 생성」을 누릅니다.
  5. 생성에는 1~3분 정도 걸릴 수 있습니다.

  ※ 바로가기 만들기
    - start.bat 우클릭 → 바로 가기 만들기 → 바탕화면으로 이동
    - 바로가기 우클릭 → 속성 → 아이콘 변경 → assets\icon.ico 선택

■ 2. 크롬 확장 프로그램
  1. Chrome 주소창에 chrome://extensions 입력
  2. 우측 상단 「개발자 모드」 켜기
  3. 「압축해제된 확장 프로그램을 로드합니다」 클릭
  4. 압축 해제한 폴더 안의 「chrome-extension」 폴더 선택
  5. 툴바의 JB 아이콘 클릭 → 계정·주제·CTA 입력 후 생성

■ 3. Electron 데스크톱 앱 (고급)
  - Node.js가 설치된 PC에서만 가능합니다.
  - desktop 폴더에서:
      npm install
      npm start
  - 설치형 exe 빌드:
      npm run pack
    (결과물: desktop\dist 폴더)

■ 계정 안내
  - 웹 서비스(https://jbai-three.vercel.app)와 동일한 이메일·비밀번호를 사용합니다.
  - 계정이 없으면 웹에서 회원가입 후 사용하세요.

■ 서버 주소 변경 (관리자)
  - lib\config.default.json 의 apiBaseUrl 값을 수정합니다.
  - 기본값: https://jbai-three.vercel.app

■ 문제 해결
  - 로그인 실패: 이메일·비밀번호 확인, 인터넷 연결 확인
  - 생성 실패: 1~3분 후 재시도, 관리자에게 API 상태 문의
  - start.bat 오류: PowerShell 실행 정책 — 관리자 PowerShell에서
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
    후 다시 실행
